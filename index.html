📦 전산 날리기

토트사진 → 상품바코드 → 진열 로케이션 순서로 입력하면 인쇄용 이미지 한 장으로 합쳐줍니다.

1 토트사진 바코드
코드를 입력하면 바코드가 표시됩니다
2 상품바코드
코드를 입력하면 바코드가 표시됩니다
3 진열할 로케이션 바코드
코드를 입력하면 바코드가 표시됩니다
바코드 생성은 서버 없이 동작하는 순수 클라이언트 기능입니다.
카메라 스캔(📷)만 Claude Vision API를 호출하며, ⚙️ 설정에서 API 키 등록이 필요합니다.
새로고침하면 입력값은 초기화됩니다(API 키/설정은 유지됩니다).
라벨을 네모 칸 안에 맞춰주세요

⚙️ 인식 설정

손상되거나 여러 코드가 섞인 라벨도 정확히 읽기 위해 카메라 스캔은 Claude Vision API로 인식합니다. 기존에 쓰시던 다른 앱(토트+IBC 앱 등)과 같은 워크스페이스 API 키를 그대로 넣으셔도 됩니다.

이 브라우저에만 저장됩니다(localStorage). 서버로 전송되지 않습니다.
쉼표(,)로 구분해서 입력. 하이픈 위치가 라벨마다 달라도 문자+숫자 구성으로 인식합니다.
이 키워드가 포함된 코드는 인식 결과에서 제외됩니다.
